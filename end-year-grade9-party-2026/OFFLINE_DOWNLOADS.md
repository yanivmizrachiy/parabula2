# הורדת המצגת לעבודה ללא אינטרנט

עודכן: 2026-06-10

## דרישת משתמש

המשתמש ביקש כפתור הורדה אמיתי למצגת המוכנה, כך שכאשר ירצה — יוכל להוריד את המצגת ולעבוד איתה גם ללא אינטרנט.

## יעד קבוע למצגת הסופית

הכפתור בדף הראשי יפנה תמיד לנתיב הקבוע הבא:

```text
end-year-grade9-party-2026/presentation/grade9-end-year-party-2026-ready.pptx
```

קישור GitHub Pages יחסי:

```text
presentation/grade9-end-year-party-2026-ready.pptx
```

כאשר הקובץ יישמר בנתיב הזה, כפתור ההורדה בדף יעבוד כהורדה אמיתית.

## יעד קבוע לחבילת Offline מלאה

אם צריך שכל החומרים, הווידאו, האודיו והמצגת יהיו יחד בחבילה אחת:

```text
end-year-grade9-party-2026/presentation/grade9-end-year-party-2026-offline.zip
```

קישור GitHub Pages יחסי:

```text
presentation/grade9-end-year-party-2026-offline.zip
```

## כלל ביצוע

- לא ליצור קובץ PPTX מזויף.
- לא לשים קובץ placeholder בשם של המצגת.
- הכפתור קיים ומוכן, אבל יעבוד בפועל רק אחרי שהמצגת האמיתית תישמר בנתיב הקבוע.
- כאשר המצגת מוכנה, יש לשמור אותה בשם המדויק: `grade9-end-year-party-2026-ready.pptx`.
- אם רוצים חבילה מלאה ללא אינטרנט, יש ליצור ZIP בשם המדויק: `grade9-end-year-party-2026-offline.zip`.

## שימוש בפועל אחרי הורדה

1. נכנסים לדף הפרויקט.
2. לוחצים על כפתור הורדת המצגת.
3. שומרים את הקובץ במחשב / דיסק און קי / טלפון.
4. פותחים את המצגת גם בלי אינטרנט.

## הערה חשובה

אם המצגת משתמשת בקישורי YouTube או Google Photos, הם לא יעבדו ללא אינטרנט. כדי לעבוד לחלוטין Offline, צריך להכניס את המדיה עצמה לתוך קובץ ה־PowerPoint או לתוך ZIP מקומי עם קבצים מצורפים.
